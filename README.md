# Cheesehead

Cheesehead - an irreverent Wisconsin game. Play: https://antonolson47-ctrl.github.io/cheesehead/

Works in desktop browsers and on phones/tablets (touch controls). On iPhone/iPad: open the link in Safari, then Share → Add to Home Screen to play full-screen. Plays in portrait or landscape — just turn the phone; the controls re-fit (landscape gives the biggest view).
